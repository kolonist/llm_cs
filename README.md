## Полные листинги примеров

Все примеры запускались на компьютере с процессором **Apple M4 Pro**, так что для запуска на иных процессорах и видеоускорителях может понадобиться незначительная адаптация.

Примеры снабжены подробными комментариями. Рекомендуется изучать их последовательно, т.к. комментарии для аналогичных уже рассмотренных конструкций в следующих примерах не повторяются.

- [sample_1](sample_1/sample_1.cs) — Минимальный пример использования LLamaSharp
- [sample_2](sample_2/sample_2.cs) — Пример ведения диалога в едином контексте
- [sample_3](sample_3/sample_3.cs) — Пример сохранения диалога и продолжения после перезапуска программы
- [sample_4](sample_4/sample_4.cs) — Продвинутый пример работы с KV-кэшом - префилл системного промпта в KV-кэш и удаление из KV-кэша ненужных данных
- [sample_5](sample_5/sample_5.cs) — Пример параллельного ведения нескольких диалогов с сохранением сессий
